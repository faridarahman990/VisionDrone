# VisionDrone

## Agricultural Crop Monitoring & Treatment Support System

VisionDrone is an ongoing precision-agriculture project exploring the use of remotely operated drones and computer vision to help farmers monitor large crop fields.

The system is being designed to capture field imagery, identify potentially infected crops, and provide visual information to the operator through a remote controller with an integrated display.

## Project Goals

- Monitor large agricultural fields efficiently
- Detect potentially infected crops using computer vision
- Provide field information to the drone operator
- Explore remote drone control and monitoring
- Map potentially affected areas
- Explore autonomous field-coverage planning
- Develop a simulated treatment-planning system
